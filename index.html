学习进度总览
把题库放到手机桌面（不需要电脑，直接手机使用）
  1. 把 index.html 这个文件发送到手机（微信文件传输助手、QQ、邮箱均可），下载保存。
  2. 在手机文件管理器里找到它，用 Chrome 或 Edge 打开（iPhone 可用微信直接打开，或用“文件”App 配合支持 JS 的浏览器）。
  3. Android：浏览器右上角菜单“⋮”→“添加到主屏幕”；iPhone：分享→“添加到主屏幕”。
  4. 桌面出现“华电题库”图标，点开即用；进度保存在手机浏览器里，完全不需要电脑。
提示：清除浏览器缓存会清空进度，建议定期点首页“导出进度”备份；若浏览器禁止保存进度，应用会自动提示。
